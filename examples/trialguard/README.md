# Example: TrialGuard

The station outputs of a small example project, used by `npm run demo` and in
the videos. Maya, a designer, wants a site that warns before a free trial
charges. Research is skipped in the demo (with the reason recorded) because
its sources would have to be real and checked; the other stations go through
the real gates.

- `01-brief.md`: the confirmed brief, with an idea check and requirements R1-R3
- `03-hooks.md`: launch copy for Reddit
- `04-screenplay.md` and `04-acceptance.json`: the plan and the visible checks
- `tests/acceptance/add-trial.mjs`: the acceptance test, written before code
- `holdout.json`: two hidden checks, sealed before the arena
