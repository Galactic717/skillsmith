Idea in. Verified product out. Ідея на вході. Перевірений продукт на виході. Liars get deleted.Брехунів видаляють.

A free plugin for Claude Code. Tell it your idea in plain words. Seven AI specialists interview you, research the market, write the copy and plan the build. Then three rival managers race their own developer and designer. A script checks every claim they make, and a team that lies is wiped.

Безкоштовний плагін для Claude Code. Розкажіть ідею простими словами. Сім AI-спеціалістів розпитають вас, дослідять ринок, напишуть тексти і спланують збірку. Потім три менеджери-суперники женуть своїх розробника й дизайнера. Скрипт перевіряє кожну їхню заяву, а команду, яка збрехала, стирає.

The lineКонвеєр

Six stations, in order. You can't skip ahead: a script checks each station's output before the next one starts.

Шість станцій по черзі. Перескочити не можна: скрипт перевіряє результат кожної станції, перш ніж почнеться наступна.

  1. 1

    InterviewІнтерв'ю

    The interviewerІнтерв'юер

    Asks one simple question at a time, like a good developer with a new client. Never "which framework?". Reads the summary back and waits for your yes.

    Питає по одному простому питанню, як добрий розробник нового клієнта. Ніколи «який фреймворк?». Читає підсумок і чекає вашого «так».

    01-brief.md

  2. 2

    ResearchДослідження

    Four researchers in parallelЧотири дослідники паралельно

    Competitors, real user voices, trends and open niches, GitHub repos. Every fact needs a link and a word-for-word quote. The script loads the page and looks for it.

    Конкуренти, справжні голоси людей, тренди й вільні ніші, репозиторії GitHub. Кожен факт — з посиланням і дослівною цитатою. Скрипт відкриває сторінку і шукає її.

    02-research.md · 02-sources.json

  3. 3

    HooksХуки

    The hook writerАвтор хуків

    Opening lines, in-product copy and a launch post for your one main platform. Numbers need a source. A detector rejects AI-slop phrases in English, Ukrainian and Russian.

    Перші фрази, тексти в продукті і пост для запуску на одному головному майданчику. Цифри — тільки з джерелом. Детектор відкидає AI-шаблони англійською, українською і російською.

    03-hooks.md

  4. 4

    ScreenplayСценарій

    The screenwriterСценарист

    The build plan written like a film: cast, acts, scenes. Every scene ends in acceptance checks that a script can run, written before any code exists.

    План збірки, написаний як фільм: дійові особи, акти, сцени. Кожна сцена закінчується перевірками, які може запустити скрипт, — написаними до першого рядка коду.

    04-screenplay.md · 04-acceptance.json

  5. 5

    ArenaАрена

    3 managers, 3 developers, 3 designers, 1 auditor3 менеджери, 3 розробники, 3 дизайнери, 1 аудитор

    Each team builds the same screenplay in its own copy of your project. Claims are checked, rivals cross-examine, the auditor scores what's left.

    Кожна команда будує той самий сценарій у своїй копії проєкту. Заяви перевіряються, суперники допитують одне одного, аудитор оцінює тих, хто лишився.

    scoreboard.md · graveyard.md

  6. 6

    ShipЗапуск

    The conveyorКонвеєр

    The winner is merged and re-checked. You get a README written for someone who has never opened a terminal, a launch kit and a report.

    Переможця зливають у проєкт і перевіряють ще раз. Ви отримуєте README для людини, яка ніколи не відкривала термінал, набір для запуску і звіт.

    README.md · LAUNCH.md · REPORT.md

Three managers. One rule.Три менеджери. Одне правило.

Lose honestly and your branch is kept. Lie once and your team is gone: the copy of the project, the branch, every line of work. The lie stays in the graveyard with the output that disproved it.

Програв чесно — твою гілку збережуть. Збрехав хоч раз — команди немає: копії проєкту, гілки, кожного рядка роботи. Брехня лишається на кладовищі разом із виводом, який її спростував.

SprintThe smallest product that fully works, shipped first.Найменший продукт, який повністю працює, і першим.
FortressNothing breaks: tests, edge cases, security, accessibility.Ніщо не ламається: тести, крайні випадки, безпека, доступність.
SparkThe boldest experience people remember.Найсміливіший досвід, який запам'ятовують.

  1. Evidence or silence. Every "done" comes with a check a script can run. "Not verified" is always allowed.

    Доказ або мовчання. Кожне «готово» — з перевіркою, яку запускає скрипт. «Не перевірено» казати можна завжди.

  2. A claim that fails its own check is a lie. The team is deleted on the spot.

    Заява, яку спростувала її ж перевірка, — брехня. Команду видаляють одразу.

  3. Tests are untouchable. A commit that changes a protected file is tampering. Same fate.

    Тести недоторкані. Коміт, що змінює захищений файл, — підробка. Той самий кінець.

  4. Accuse only with proof. If the script can't reproduce the defect you reported, you are the one deleted.

    Звинувачуй тільки з доказом. Якщо скрипт не відтворить дефект, видалять тебе.

  5. The judge checks your commit, not your desk. Every verdict runs in a fresh copy of what you committed.

    Суддя дивиться на коміт, а не на стіл. Кожен вердикт іде в чистій копії того, що закомічено.

Score: acceptance checks 50, verified claims up to 10, proven defects in rivals +3 each, defects proven against you −4 each, the auditor up to 30. The auditor uses each product the way your customer would and must cite what it saw for every point. You pick the winner; the scoreboard only recommends.

Бали: перевірки приймання 50, доведені заяви до 10, доведені дефекти суперників +3 за кожен, дефекти, доведені проти тебе, −4 за кожен, аудитор до 30. Аудитор користується кожним продуктом як ваш клієнт і для кожного бала вказує, що саме побачив. Переможця обираєте ви; табло лише радить.

QuestionsПитання

Does it really delete a team's work?Він справді видаляє роботу команди?

Yes. The team's git worktree and branch are removed, and the team name can never be used again in that project. What stays is the dossier: the claim, the check and the output that disproved it.

Так. Робоча копія (git worktree) і гілка команди видаляються, а ім'я команди більше не можна використати в цьому проєкті. Лишається досьє: заява, перевірка і вивід, що її спростував.

What if a check fails for a silly reason?А якщо перевірка впаде через дурницю?

Managers run a private precheck first; it runs exactly what the official check runs and kills nobody. A timeout or an unsafe command counts as "unproven", not as a lie. Only a check that ran and contradicted the claim kills.

Менеджери спершу роблять приватну перевірку: вона запускає те саме, що й офіційна, і нікого не вбиває. Тайм-аут чи небезпечна команда — це «не доведено», а не брехня. Вбиває тільки перевірка, яка відпрацювала і суперечить заяві.

Where does my project go?Куди потрапляє мій проєкт?

Nowhere. Skillsmith has no server. Everything lives in your folder, in .skillsmith/, under git. The researchers use the web tools your Claude Code already has.

Нікуди. У Skillsmith немає сервера. Усе лежить у вашій папці, у .skillsmith/, під git. Дослідники користуються веб-інструментами, які вже є у вашому Claude Code.

Which languages does it speak?Якими мовами він говорить?

The interviewer answers in the language you write in, and every human-readable file follows it. The slop detector knows English, Ukrainian and Russian clichés.

Інтерв'юер відповідає мовою, якою пишете ви, і всі файли для людей — тією ж мовою. Детектор шаблонів знає штампи англійською, українською і російською.

Does it work outside Claude Code?Чи працює він поза Claude Code?

The plugin has no bin/ folder, so Claude Cowork can install it. The skills use the open Agent Skills format; the arena needs subagents and a shell, so other tools may run only parts of it.

У плагіні немає теки bin/, тож його може встановити Claude Cowork. Навички у відкритому форматі Agent Skills; арені потрібні субагенти й термінал, тому інші інструменти можуть запустити лише частину.
