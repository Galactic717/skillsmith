# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique the work and not the person,
and make room for people who are new to software. Founders without a
technical background are this project's main audience; questions from them
are always welcome.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/galactic717). Reports are handled confidentially.
