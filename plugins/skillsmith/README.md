# Skillsmith plugin

Idea in, verified product out. Start with `/skillsmith:start` in an empty
folder and describe your idea in your own words.

- `skills/`: the foreman (`start`), one skill per station (`interview`,
  `research`, `hooks`, `screenplay`, `arena`, `ship`) and `status`
- `agents/`: researcher, hook-writer, screenwriter, manager-sprint,
  manager-fortress, manager-spark, developer, designer, auditor
- `scripts/skillsmith.mjs`: the engine (Node.js 18+, no dependencies)
- `templates/`: the shape of every artifact
- `hooks/hooks.json`: session context and protected-file guard

Requirements: Claude Code, git, Node.js 18+. Full documentation:
https://github.com/galactic717/skillsmith
